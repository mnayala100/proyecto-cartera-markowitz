# Optimización de carteras (Markowitz)

Proyecto personal en Python: construyo la frontera eficiente con datos reales
y compruebo, con un backtest fuera de muestra, si la cartera óptima supera a
repartir el dinero a partes iguales.

## Estructura
- `data/`: precios descargados
- `notebooks/`: exploración y resultados
- `src/`: funciones reutilizables

## Cómo ejecutarlo
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
